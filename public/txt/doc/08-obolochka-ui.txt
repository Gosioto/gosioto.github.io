================================================================================
  08. Модуль оболочки UI (Shell)
================================================================================

Назначение
----------
  Общие элементы навигации и UX, повторяющиеся на большинстве страниц:
  шапка, подвал, вкладка новостей, прокрутка наверх, вспомогательные виджеты.

Точки входа
-----------
  Импортируются из src/app/*/page.tsx (не отдельный маршрут).

Компоненты
----------
  Header.tsx
    Роль: логотип, меню, активная ссылка по маршруту.
    State: isMenuOpen (бургер на мобильных).
    Реализация: usePathname() из next/navigation; ссылки <a href>.
    Стили: @/styles/header.css
    Пункты: /, /about/, /skills/, /projects/, /hobbies/, /contact/, /freelance/

  Footer.tsx
    Роль: копирайт, Tailwind-классы (py-4, bg-[#343a40]).
    Props: нет.

  NewsTab.tsx
    Роль: плавающая кнопка «Новости» + модальное окно changelog.
    State: showModal, setShowModal (опционально с страницы); внутренний newsData[].
    Данные: массив NewsItem inline (date, version, text, importance, category).
    Хук: useGradientAnimation — реверс CSS-анимации градиента при hover.
    Стили: @/styles/news-tab.css
    Props: showModal?, setShowModal? — для синхронизации с Escape на /about/, /contact/

  ScrollToTop.tsx
    Роль: кнопка возврата к началу страницы при скролле.
    Стили: @/styles/scroll-to-top.css

  PageWrapper.tsx
    Роль: обёртка контента (если используется на отдельных маршрутах).

  StubbornButton.tsx
    Роль: интерактивная кнопка «догонялок» (пасхалка, уходит от курсора).

Фичи
----
  • Мобильное меню Header (toggle класса active)
  • NewsTab: фильтрация/группировка новостей по версиям в модалке
  • Закрытие модалки новостей по Escape (на страницах, где передан state)

Способ реализации
-----------------
  • Все перечисленные — 'use client' где нужен браузерный API
  • Навигация через обычные <a>, не только Link — предсказуемо на static host
  • NewsTab не тянет данные с сервера — статический массив в компоненте

Зависимости
-----------
  hooks/useGradientAnimation.ts ← NewsTab
  Font Awesome (layout) — иконки в NewsTab и других секциях

Ограничения / техдолг
---------------------
  • /hobbies/ не подключает NewsTab и ScrollToTop
  • /freelance/ использует отдельную шапку (см. 16)
  • Changelog дублирует информацию из git; обновляется вручную в NewsTab
