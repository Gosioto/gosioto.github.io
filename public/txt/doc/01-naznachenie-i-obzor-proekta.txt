================================================================================
  01. Назначение и обзор проекта Gosloto-site
================================================================================

Репозиторий
-----------
  URL (package.json): https://github.com/Gosioto/Gosloto-site.git
  Название пакета: gosloto-site
  Версия: 0.1.0 (private)
  Публичный сайт: https://gosioto.github.io

Что это
-------
  Личный лендинг / сайт-визитка веб-разработчика (Иван, Gosloto): навыки,
  проекты, кейсы, контакты, хобби, игровая статистика Steam, отдельная
  страница Freelance. Интерфейс на русском языке.

  Исторически сайт начинался на чистом HTML/CSS/JS; текущая реализация —
  Next.js 15 (App Router) + React 18 + TypeScript со статическим экспортом.

Роль в инфраструктуре
---------------------
  Сборка: next build → каталог out/ → статический хостинг (GitHub Pages).
  В package.json указан homepage: https://gosioto.github.io/Gosloto-site —
  при деплое с кастомного домена на корень (gosioto.github.io) basePath
  обычно не нужен; при project site — проверьте пути к ассетам (см. 05).

Архитектура (кратко)
--------------------
  src/app/          — маршруты Next App Router (page.tsx, layout.tsx)
  src/components/   — UI-модули по доменам (games, hobbies, freelance, …)
  src/data/         — статические данные (проекты, навыки, игры, опыт)
  src/types/        — TypeScript-интерфейсы
  src/styles/       — глобальные CSS по страницам/секциям
  src/hooks/        — переиспользуемые хуки (анимации)
  public/           — статика + legacy HTML-демо кейсов + эта документация

  Поток: page.tsx → компоненты секций → data/*.ts → рендер в браузере.
  Серверного API в рантайме нет (static export).
