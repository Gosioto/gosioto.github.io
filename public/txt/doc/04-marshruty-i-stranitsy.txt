================================================================================
  04. Маршруты и страницы (App Router)
================================================================================

Базовые правила URL
-------------------
  next.config.ts: trailingSlash: true
  Итоговые URL на хостинге: /, /about/, /contact/, /hobbies/games/ и т.д.

  Навигация в Header использует <a href="..."> (не только next/link) —
  совместимость со static export и прямыми переходами.

Общая оболочка страниц
----------------------
  Большинство маршрутов: Header + main + Footer + NewsTab + ScrollToTop.
  Исключения:
    • /freelance/ — свой FreelanceHeader/Footer, без общего Header
    • /hobbies/ — без NewsTab и ScrollToTop в текущей реализации
    • /hobbies/games-enhanced/ — без Header/Footer (полноэкранный UI)

Метаданные
----------
  layout.tsx: title «Визитка Gosloto», description для всего сайта.
  Отдельные page.tsx не экспортируют metadata (клиентские страницы).
