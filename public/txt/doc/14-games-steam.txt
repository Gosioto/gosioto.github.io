================================================================================
  14. Модуль игр Steam (/hobbies/games/, /hobbies/games-enhanced/)
================================================================================

Назначение
----------
  Витрина игрового профиля: кастомная шапка, топ-5, recent, скриншоты,
  перетаскиваемая Steam-панель, модалка игры с галереей. Данные — static
  snapshot (GitHub Pages, без live Steam API у посетителей).

Канонический маршрут
--------------------
  /hobbies/games/

  Точка входа: src/app/hobbies/games/page.tsx
  Без глобального Header — своя GamesHeaderBar
  Оболочка: GamesProfilePage + Footer + NewsTab + ScrollToTop
  Стили: src/styles/games-profile.css

Компоненты (канон)
------------------
  GamesHeaderBar.tsx         — sticky шапка: якоря + CTA Steam
  GamesHero.tsx              — full-bleed hero
  FavoriteGames.tsx          — топ-5 (клик → модалка)
  RecentGames.tsx            — последние 5 (клик → модалка)
  GamesScreenshotsSection.tsx — обзорная мозаика + lightbox
  GamesSecondary.tsx         — агрегаты + библиотека (клик → модалка)
  SteamDock.tsx              — draggable панель (desktop) / sheet (mobile)
  GameDetailModal.tsx        — capsule-иконка, мета, галерея по gameId

Структура страницы
------------------
  HeaderBar → Hero → Топ-5 → Последние 5 → Скриншоты → Библиотека
  + SteamDock + GameDetailModal

Данные (только static)
----------------------
  src/data/gamesData.ts
    profileMeta, topGames, recentGames, gamesData, gameStats
    У каждой игры: appId, gameId

  src/data/screenshotsData.ts
    localScreenshots + merge с generatedScreenshots
    filterScreenshots(gameId)

  src/data/screenshotsData.generated.ts
    Пишется скриптом steam:screenshots (может быть пустым)

Парсер скриншотов Steam (offline)
---------------------------------
  npm run steam:screenshots
  → scripts/fetch-steam-screenshots.mjs
  → public/img/screenshot/steam/{appId}/
  → src/data/screenshotsData.generated.ts

  Затем: commit ассетов → npm run build → деплой out/
  Если Steam отдаёт login wall — предыдущий снимок не затирается.

Правило хостинга
----------------
  • Нет запросов к steamcommunity в браузере посетителя для парсинга.
  • CDN Steam для header/capsule допустим.
  • Галерея — локальные файлы public/img/screenshot/...

Экспериментальный маршрут
-------------------------
  /hobbies/games-enhanced/ — не канон; те же gamesData.

Зависимости
-----------
  18 (данные), 13 (ссылка с hobbies)

Ограничения
-----------
  • Снимок устаревает, пока не обновлён вручную / скриптом.
  • Полный список игр Steam Community часто требует логин.
