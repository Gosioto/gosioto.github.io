# 🎨 Логотипы ACHERON

## 📋 Описание

Эта папка предназначена для логотипов и брендинга ACHERON.

## 📁 Ожидаемые файлы:

### Основные логотипы:
- `acheron-logo.svg` - основной логотип (рекомендуется SVG)
- `acheron-icon.svg` - иконка для фавиконки
- `acheron-wordmark.svg` - текстовый логотип

### Варианты:
- `acheron-logo-dark.svg` - темная версия
- `acheron-logo-light.svg` - светлая версия
- `acheron-logo-monochrome.svg` - монохромная версия

### Размеры:
- `acheron-logo-16x16.png` - для мелких элементов
- `acheron-logo-32x32.png` - для header
- `acheron-logo-64x64.png` - для крупных элементов
- `acheron-logo-128x128.png` - для hero секций

## 🎯 Использование:

```tsx
// В Header компоненте
<img src="/images/logos/acheron-logo.svg" alt="ACHERON" />

// Для фавиконки
<link rel="icon" href="/images/logos/acheron-icon.svg" />
```

## 📏 Рекомендации:
- **Формат**: SVG для векторных логотипов, PNG для растровых
- **Размеры**: Создавайте в высоком разрешении для масштабирования
- **Цвета**: Поддерживайте светлую и темную темы
- **Прозрачность**: Используйте прозрачный фон для универсальности
